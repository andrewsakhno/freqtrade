# Торговый регламент бота NFI X7 (dry-run, Binance USDT-M Futures)

Документ описывает правила, по которым работает бот `NFI_Dry` (порт 8087, сервер 85.122.114.77) со стратегией **NostalgiaForInfinityX7EMA200** — подклассом-обёрткой над **NostalgiaForInfinityX7**, добавляющим макро-трендовый фильтр EMA200 (с 2026-08-26, см. раздел 2а). Режим — **бумажная торговля (dry-run)**: сделки симулируются, капитал не рискует. Цель прогона — накопление статистики по парам и обкатка реверсивных сигналов.

---

## 1. Рынок и рамочные условия

| Параметр | Значение |
|---|---|
| Биржа / сегмент | Binance, бессрочные фьючерсы USDT-M |
| Маржа / плечо | Изолированная маржа, плечо **3x** (одинаково для всех режимов) |
| Рабочий таймфрейм | 5 минут; подтверждение по старшим ТФ: 15m, 1h, 4h, 1d |
| Вселенная инструментов | Топ-100 пар по обороту (VolumePairList из 130 с фильтрами: возраст листинга ≥ 60 дней, фильтры цены, спреда и стабильности диапазона, чёрный список) |
| Лимит позиций | Не более **6 одновременных позиций**; лимитов отдельно на лонг/шорт нет |
| Размер позиции | `unlimited` — капитал делится равномерно между свободными слотами |
| Направления | Лонг и шорт |

## 2. Сигналы входа

Стратегия — портфель независимых условий входа («сигналов»), каждый со своим номером и режимом сопровождения. Активны следующие.

### Лонг — базовый набор X7
- **Normal** (#1–#6): покупка глубокой перепроданности с многоуровневыми защитами по старшим ТФ.
- **Pump** (#21): вход после памп-коррекции с защитой `global_protections_long_pump` (не покупать в разгон).
- **Quick** (#41–#46) и **Trend Reversal** (#47): быстрые откаты и развороты тренда.
- **Rebuy** (#61–#63), **Trend Pullback** (#64), **Breakout** (#65): режим с плановым доусреднением (см. раздел 3).
- **Rapid** (#101–#104): краткосрочные импульсные входы.
- **Grind** (#120): отдельный «грайндовый» вход малой долей (только на монетах из белого списка `grind_mode_coins`, максимум 1 слот, ступени 20–50% базовой ставки).
- **Top Coins** (#141–#145): смягчённые условия для монет высшей капитализации.
- **Scalp** (#161–#163): скальповые входы с укороченным сопровождением.

### Лонг — экспериментальный реверсивный блок (включён через конфиг 2026-08-25)
- **#7** — «рождение тренда» по ADX: 4h ADX пересекает 20 снизу вверх после ~8 дней ниже 20 (вход на окончании консолидации/боковика).
- **#10** — дивергенция CCI + зарождение тренда по AROON.
- **#11** — двойная дивергенция MFI/CMF + возврат к средней полосе Боллинджера.
- **#170** — «ловец отскока после обвала»: покупка релиф-ралли после капитуляции, с фильтрами от второй ноги падения (dead-cat).
- **#192** — стохастический откат «quad rotation».
- **#193** — истинная пивотная дивергенция «quad rotation».

### Шорт
- **Normal** (#501, #502): продажа перекупленности в нисходящем контексте.
- **Quick** (#542): быстрый шорт-откат.
- **Trend Breakdown** (#562): пробой поддержки вниз.
- **#505 — «рождение нисходящего тренда» по ADX** (включён через конфиг 2026-08-25, экспериментальный): зеркало #7 — выход из боковика вниз.
- **#666 — «уловитель Bull Trap»** (включён через конфиг 2026-08-25, экспериментальный): медвежий Swing Failure Pattern — свеча прокалывает максимум предыдущих 48 свечей фитилём, но закрывается обратно ниже него. Ложный пробой вверх продаётся в шорт. Сопровождается глобальными шорт-защитами (`protections_short_global`).

Каждый сигнал проходит общий блок защит: достаточная история свечей, отсутствие пропусков данных, глобальные фильтры перегретости/перепроданности по 4h/1d (включая фильтр длинных верхних фитилей — косвенную защиту от покупки бычьих ловушек).

## 2а. Макро-трендовый фильтр EMA200 (с 2026-08-26)

Поверх **всех** сигналов входа (базовых и экспериментальных, лонг и шорт) действует жёсткий фильтр по 200-периодной EMA рабочего таймфрейма 5m:

- **Лонг** разрешён только при `close > ema200`;
- **Шорт** разрешён только при `close < ema200`;
- пока EMA200 не прогрелась (NaN в начале истории), входы блокируются в обе стороны.

Назначение — не «ловить падающие ножи»: перепроданные лонг-сигналы против глобального нисходящего движения и шорты против восходящего отсекаются. На выходы и сопровождение позиций фильтр не влияет — уже открытые сделки ведутся по обычной логике X7.

Технически фильтр реализован не правкой файла X7 (его ежедневно перезаписывает авто-апдейтер), а подклассом `/opt/nfi/NostalgiaForInfinityX7EMA200.py`, подключённым через `docker-compose.override.yml` (переменная `FREQTRADE__STRATEGY` + монтирование файла). Апдейтер продолжает обновлять базовую стратегию; фильтр переживает обновления. Откат: восстановить `docker-compose.override.yml.bak-ema200` и пересоздать контейнер.

> Нюанс масштаба: EMA200 на 5m покрывает ~16,5 часов — это скорее интрадей-тренд. Возможное ужесточение — перейти на уже имеющиеся в датафрейме `EMA_200_1h` / `EMA_200_4h` (правка одной строки в обёртке).

## 3. Сопровождение позиции (position adjustment)

Доусреднение и «грайндинг» включены (`position_adjustment_enable`, `grinding_enable`).

- **Обычные режимы**: первый вход — 100% расчётной ставки; далее ступени докупок 3–26% от базовой ставки на просадках примерно от −3% до −16% (пять уровней грайнда с разными порогами). Каждая докупленная доля фиксируется отдельно при достижении **+1.8%** (последний уровень +4.8%) по этой доле.
- **Rebuy-режим** (#61–#65): вход изначально частичный, план докупок 10% + 10% + 10% на −12% / −14% / −16%; требует минимум 2 свободных слота.
- **Derisk**: при ухудшении картины позиция частично разгружается (сокращение экспозиции) вместо полного стопа; стоп грайндовых долей — **−12%**, предельный стоп грайнда −20%.

## 4. Выходы

- `minimal_roi` не используется (пустой) — выходы полностью сигнальные.
- Каждый режим имеет собственную логику выхода (`long_exit_normal`, `long_exit_pump`, `short_exit_pump` и т.д.): комбинация целевых уровней прибыли, ослабления импульса (RSI/WillR/CMF по нескольким ТФ) и внутреннего трейлинга через кэш целевой прибыли (`target_profit_cache`) — цель подтягивается за ценой и продаёт при откате от максимума.
- Стандартный биржевой trailing stop отключён; ордера — лимитные (вход, выход, стоп).

## 5. Риск-менеджмент

| Механизм | Порог | Комментарий |
|---|---|---|
| Формальный стоп-лосс freqtrade | −99% | Аварийный предохранитель; реальные стопы — внутренние |
| Внутренний стоп (обычные режимы) | **−10%** от первого входа | `stop_threshold_futures` |
| «Doom»-стоп | −20% | Жёсткая отсечка катастрофического сценария |
| Стоп Rapid / Scalp режимов | −20% | Укороченные режимы несут больший разовый риск |
| Rebuy-режим | стоп фактически отключён (−100%) | Риск управляется ступенями докупок и derisk |
| Стоп грайндовых долей | −12% | `grinds_stop_futures` |

Незаполненные лимитные заявки снимаются: вход — через 3 минуты, выход — через 2 минуты.

## 6. Текущий фокус прогона

1. **Статистика по парам** — накопить результативность в разрезе пар и сигналов, чтобы решить, какие пары и условия входа оставить.
2. **Реверсивная торговля** — оценка экспериментального блока #10 / #11 / #170 / #192 / #193 (лонг) и #666 «bull trap» (шорт). Все включены не правкой кода, а через `nfi_parameters` в `user_data/config.json` бота.
3. **Фильтр EMA200** — оценить, как макро-трендовый фильтр (раздел 2а) влияет на частоту входов и качество сделок; реверсивные сигналы теперь срабатывают только по направлению тренда EMA200.

> Напоминание: проект серверный, локальный. Не публиковать в удалённые репозитории.
